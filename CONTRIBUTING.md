# Contributing

This is the **feedback and issue-tracking** repository for [Angular Architect](https://plugins.jetbrains.com/plugin/31306-angular-architect). The plugin source lives in a separate private repository — you can't submit code PRs here.

You can still help enormously, in three ways:

## 1. File a good issue

The issue templates guide you through the information that makes a report actionable without a back-and-forth. A few extra tips:

- **One issue per problem.** If you've hit three unrelated things, please file three issues — it makes triage and closing much cleaner.
- **Include the smallest reproduction you can.** For false positives, a 5-line component + 1-line template is usually enough; you don't need to attach your whole workspace.
- **Search first.** [Existing issues](../../issues?q=is%3Aissue) may already cover what you're seeing — a 👍 reaction on an existing report is more useful than a duplicate.
- **The plugin version and IntelliJ version matter.** Angular's ergonomics shift enough between majors that a bug reproducing on v18 may not on v20, and vice versa. The templates ask for these because triaging without them takes 3× as long.
- **Say which tier you're on.** Since 2.0.0 the plugin is free and Pro. Whether you're on the free tier, a trial, or a paid license changes what a "tab doesn't work" report means.
- **Scrub Kubernetes output.** Remove cluster names, hostnames, tokens, and Secret values from logs and screenshots — issues here are public.
- **Billing goes to JetBrains.** Purchases, invoices, and refunds are handled by [JetBrains sales support](https://sales.jetbrains.com/hc/en-gb), not here. A Pro feature that stays locked with an active license *is* a plugin bug — file that here.

## 2. Vote and discuss

- Upvote issues that matter to you with a 👍 reaction. Reactions are the primary signal I use when deciding what to work on next.
- Open a [Discussion](../../discussions) for anything open-ended — "how would you approach X" or "does anyone else want Y" — instead of filing it as an issue. Discussions are lower-friction and don't need to be closed.

## 3. Improve the ecosystem around the plugin

- **Rate on JetBrains Marketplace** — [leave a review](https://plugins.jetbrains.com/plugin/31306-angular-architect/reviews). A five-star review with a sentence about what you actually use the plugin for helps the Marketplace ranking more than a raw star count does.
- **Tell one other Angular dev.** Angular Architect is discovered almost entirely by word of mouth in the IntelliJ + Angular Nx community. If you know someone who'd get value from it, sharing takes 30 seconds and helps enormously.
- **Support the work.** Buying a Pro license is the most direct way. If you only use the free tier, see [DONATE.md](./DONATE.md) — every donation is genuinely appreciated.

## Response times

I aim to respond to every issue within a week. Complex bugs and larger feature requests may take longer to work through — a response of "I'll look at this in the next minor" is common. Free-tier and Pro reports go through the same queue. If an issue has been open for more than two weeks without any response from me, please leave a comment mentioning `@eddyboutros` to nudge it — sometimes GitHub notifications get lost.

## Ground rules

Please be respectful and constructive. Comments that don't add information or are personal attacks will be hidden without warning. This is a project I maintain on my own; I want everyone who shows up here to feel welcome.

Thanks for helping make Angular Architect better.
