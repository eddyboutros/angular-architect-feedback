# Contributing

This repository is the issue tracker for [Angular Architect](https://plugins.jetbrains.com/plugin/31306-angular-architect). The plugin's source is in a private repository, so there is no code to send pull requests against. You can still help in three ways.

## 1. File a good issue

The issue forms ask for most of what I need. A few more things make a report easier to act on:

- Keep it to one problem per issue. If you hit three unrelated things, please file three issues.
- Include the smallest example that shows the problem. For a false positive, a five-line component and one line of template is usually enough. I don't need your whole workspace.
- Search the [existing issues](../../issues?q=is%3Aissue) first. If yours is already there, a 👍 on it tells me more than a duplicate does.
- Give the plugin, IDE and Angular versions. A bug on Angular 18 often does not reproduce on Angular 20, and without the versions I have to guess.
- Say which tier you are on. Since 2.0.0 the plugin has a free tier and a Pro tier, and "the tab doesn't work" means something different on each.
- If the report involves Kubernetes, remove cluster names, hostnames, tokens and Secret values from logs and screenshots. Issues here are public.

Questions about purchases, invoices and refunds go to [JetBrains sales support](https://sales.jetbrains.com/hc/en-gb), because JetBrains sells the licenses. If a Pro feature stays locked although your license is active, that is a plugin bug, so please file it here.

## 2. Vote and discuss

Add a 👍 to the issues you care about. I look at reactions when I decide what to work on next.

For anything open-ended, such as "how would you approach X" or "does anyone else want Y", please open a [Discussion](../../discussions) instead of an issue.

## 3. Spread the word

- [Leave a review](https://plugins.jetbrains.com/plugin/31306-angular-architect/reviews) on JetBrains Marketplace. A sentence about what you use the plugin for is more useful to other people than stars alone.
- Tell another Angular developer. Most people find the plugin by word of mouth.
- If the Pro features are useful to you, buy a license. If you only use the free tier and want to give something back, see [DONATE.md](./DONATE.md).

## Response times

I try to reply to every issue within a week. Harder bugs and bigger feature requests take longer, and you will often get an answer like "I'll look at this for the next minor release". Reports from free and Pro users go through the same queue.

If two weeks pass without a reply from me, please comment and mention `@eddyboutros`. GitHub notifications do get lost sometimes.

## Ground rules

Please be respectful and constructive. I will hide comments that are personal attacks or add nothing to the discussion. I maintain this project on my own and I want everyone who comes here to feel welcome.

Thanks for helping make Angular Architect better.
