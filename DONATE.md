# ❤️ Support Angular Architect

Since 2.0.0, Angular Architect is **free and Pro**: most of the plugin is free, and the Pro features need a license from JetBrains Marketplace.

**The simplest way to support the project is to buy a Pro license** from the Pricing tab of the [Marketplace listing](https://plugins.jetbrains.com/plugin/31306-angular-architect), if the Pro features are useful to you.

This page is for people who use only the free tier and still want to give something back. **A donation is a gift: it does not include or unlock a Pro license.**

## Where it goes

A set of automated workflows refreshes the bundled Angular metadata, schematic-surface, compat-matrix, deprecated-packages, and update-guide catalogs — so the plugin's upgrade advice stays current at release time, not just at install time. Every patch Angular ships triggers a review-and-verify cycle that gets folded into the next plugin release. On top of that comes bug triage from Marketplace reviews, false-positive reports filed here, and tracking the Angular team's roadmap so the plugin's version gating stays honest. All of that serves the free tier too.

## Can't donate? You can still help a lot

- ⭐ **Rate the plugin** on [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/31306-angular-architect/reviews) — a five-star review with one sentence about what worked for you does more than you'd think.
- 🐛 **File a good bug or feature request** — well-scoped [issues](https://github.com/eddyboutros/angular-architect-feedback/issues/new/choose) are how the plugin gets better.
- 📣 **Tell one other Angular developer about it** — the plugin is discovered almost entirely by word of mouth.
