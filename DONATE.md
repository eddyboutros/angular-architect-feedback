# ❤️ Support Angular Architect

**Angular Architect is free and always will be.**

Keeping it that way costs real hours every week: a set of automated workflows runs daily to refresh the bundled Angular metadata, schematic-surface, compat-matrix, deprecated-packages, and update-guide catalogs — so the plugin's upgrade advice stays current at release time, not just at install time. Every patch Angular ships triggers a review-and-verify cycle that gets folded into the next plugin release. On top of that comes bug triage from Marketplace reviews, false-positive reports filed here, and tracking the Angular team's roadmap so the plugin's version gating stays honest.

If Angular Architect saves you time, a donation — however small — genuinely helps keep this work alive and free for everyone.

## Can't donate? You can still help a lot

- ⭐ **Rate the plugin** on [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/31306-angular-architect/reviews) — a five-star review with one sentence about what worked for you does more than you'd think.
