# Supporting Angular Architect

Since version 2.0.0, Angular Architect has a free tier and a paid Pro tier. If the Pro features are useful to you, buying a license from the Pricing tab of the [Marketplace page](https://plugins.jetbrains.com/plugin/31306-angular-architect) is the best way to support the plugin.

This page is for people who only use the free tier and still want to give something back. Please note that a donation is a gift. It does not include a Pro license and does not unlock Pro features.

## Where the money goes

It pays for my time. Angular ships often, and the plugin bundles a lot of Angular data that has to keep up: API metadata, schematics, the compatibility matrix, deprecated packages and the update guide. Automated jobs refresh that data, and I review each refresh before it goes into a release. On top of that there are the bugs and false positives reported here and on Marketplace. The free tier depends on all of this too.

## Other ways to help

- Leave a review on [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/31306-angular-architect/reviews). A sentence about what worked for you is enough.
- File a clear [bug report or feature request](https://github.com/eddyboutros/angular-architect-feedback/issues/new/choose).
- Tell another Angular developer about the plugin. Most people find it by word of mouth.
